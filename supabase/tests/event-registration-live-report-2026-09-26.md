## 初测发现的三个线上问题（现已修复，见上文）

1. **自助注销接口缺失。** 线上不存在 `public.delete_user_account()`，而 App 的个人设置页面仍调用它。自助注销及其后续释放名额流程因此无法完成线上验证。管理员删除账号的独立接口已测通过，不能替代自助注销验收。需要补齐与现有身份验证流程匹配的接口并回归。
2. **自动通知 Edge Function 仍是旧版。** 只读下载检查到线上版本 2 使用旧的 `event_id` 协议，而 041 的新任务使用 `job_id`；线上 GET 探测返回 HTTP 500。需要重新部署仓库中的新函数，Git push 本身不等于部署。
3. **自动通知 Vault 密钥缺失。** 线上不存在 `event_registration_start_secret_key`。只检查存在性和名称，未读取或展示密钥值。需要配置与函数验证一致的密钥，然后使用测试设备验证定时触发及实际收件。

初测当时只测试和报告，未实施修复；用户随后授权修复，执行结果见上文。测试设备实际收件仍待验收。

## 测试边界

- 这是线上真实 SQL/RPC/RLS 的顺序事务测试，**不是 200 个独立连接同时提交或取消的并发压测**。旧版本冲突和座位被先占用已覆盖，但不能将其称为真实并发验证。
- 没有真机断网、请求已提交但响应丢失、登录过期或移动网络切换的端到端测试；也没有验证每个客户端弹窗的实际显示。
- 导出检查覆盖数据库导出快照的完整性；本轮未在手机生成并打开 XLSX 文件验证格式和分享流程。
- 推送检查不包含手机实际收到通知。上述部署阻塞已修复，数据库到函数的鉴权通信已通过无发送探测。
- 先前本地 302 条 SQL 断言、38 项推送检查、4 组时间测试及 TypeScript 检查属于另一层验证，不计入本报告 60 项线上测试。
